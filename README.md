# 🛒 Lista de Compras 
Este é um sistema simples de lista de compras, desenvolvido usando HTML, CSS e JavaScript. 
O sistema permite ao usuário adicionar itens à lista, editar, excluir e limpar a lista de compras de maneira interativa. 
Ele segue o padrão CRUD (Create, Read, Update, Delete) para gerenciar os itens.

# 🚀 Funcionalidades
* Adicionar Item: Permite adicionar um item à lista de compras.
* Exibir Itens: Mostra todos os itens adicionados à lista.
* Editar Itens: Permite editar os itens da lista.
* Excluir Itens: Exclui um item específico da lista.
* Limpar Lista: Remove todos os itens da lista de uma vez.
  

# 🖥️ Como Usar
1. Clone o repositório:

```bash
git clone https://github.com/analuisaabarbosa/lista-de-compras.git
```
2. Abra o arquivo index.html no navegador ou Live Server para usar.
